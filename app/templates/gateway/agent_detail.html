Windows-Druckagent installieren
  1. Windows-x64-ZIP herunterladen und vollständig entpacken. Das Paket 2026.10.17 enthält Installations- und Pairing-Fehler; die korrigierte Version 2026.10.23 mit Installieren.cmd verwenden.
  2. Netzwerkdrucker als lokale Windows-Warteschlange mit TCP/IP-Anschluss einrichten.
  3. Hier einen Pairing-Code erzeugen (einmal verwendbar, 10 Minuten gültig).
  4. Installieren.cmd per Rechtsklick als Administrator ausführen und den Code eingeben. Für diese Cloud alternativ in einer Administrator-PowerShell im entpackten Ordner: .\install.ps1 -CloudUrl "{{ cloud_url }}" – der Code wird verdeckt abgefragt.
  5. Die Meldung „mit Einsatzcockpit verbunden“ abwarten, diese Seite neu laden und unten die Windows-Warteschlange einem Druckziel zuordnen. Anschließend beim Druckziel eine Testseite drucken und den Ausdruck kontrollieren.

Bei anderem Cloud-Host immer den PowerShell-Befehl mit der hier angezeigten URL verwenden. Bei abgelaufenem oder bereits verwendetem Code einen neuen erzeugen. Bei „Offline“ HTTPS/WSS über Port 443, Proxy und den Tray-Status prüfen. Bei blockiertem Skript im entpackten Ordner powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -CloudUrl "{{ cloud_url }}" ausführen (organisationsweite Richtlinien gelten weiterhin). Dienstkonto und Windows-Passwort sind für lokale TCP/IP-Drucker nicht erforderlich.
