{{ icon("info-circle") }} Hinweis

Die API liefert aktuell keine Leitstellennummer. Einsätze aus dem LIS werden daher über Einsatzgrund, Adresse und Alarmstichwort innerhalb eines 3-Stunden-Fensters mit bereits über die API angelegten Einsätzen verbunden. Kommt ein Einsatz zuerst über das LIS, wird er selbst angelegt. Fahrzeugstatus (S4/S5) wird nur für Fahrzeuge übernommen, die unter Ressourcen eine LIS-ReferenceId hinterlegt haben. Liefert das LIS zu einem Fahrzeug Koordinaten (i.d.R. ab Status "am Einsatzort"), werden diese in dieselbe Positionshistorie wie die App-GPS-Positionen geschrieben — auf der Lagekarte gewinnt je Fahrzeug automatisch die zuletzt empfangene Position.

{{ icon("plug-connected") }} Verbindung

Schaltet den Hintergrund-Abgleich mit dem LIS für diese Organisation ein

Schreibt manuell im Einsatzcockpit gesetzte Fahrzeugstatus (S1/S4/S5) aktiv zurück ins LIS (SetOperationUnitStatus). Schreibt in das echte Leitstellensystem — im Zweifel deaktiviert lassen.

Übernimmt bei Großereignissen (z.B. F4) auch teilnehmende Fahrzeuge fremder Organisationen (Nachbarwehren, Rotes Kreuz) als externe Fahrzeuge ins Board/die Lagekarte, sobald das LIS "zum Einsatzort"/"am Einsatzort" meldet. Ohne diesen Schalter werden fremde Einheiten wie bisher ignoriert.

Ohne abschließenden Schrägstrich, z.B. https://lis.lwz-vorarlberg.at/ipr
