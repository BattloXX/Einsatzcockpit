{{ icon("info-circle") }} Hinweis

DIBOS EventHub ist eine eigenständige, einfachere Schnittstelle als LIS/IPR (siehe LIS-Anbindung) — die Antworten sind JSON statt SOAP-XML. Diese Seite liest primär mit: es wird NIE ein Einsatz angelegt. Optional (Schalter unten, Default aus) kann ein bereits bestehender, aktiver Einsatz um Zusatzinfos ergänzt werden (Einsatzort, Einsatzcode/Diagnose, BMA-Nr., Meldungsprotokoll) — siehe Einsatz-Infos. Es gibt zwei getrennte Zugangsdaten: ein vom Betreiber vergebenes Gateway-Konto (HTTP-Basic) und das eigene Org-Servicekonto (im SOAP-Header übertragen).

{{ icon("list-details") }} Einsatz-Infos

{{ icon("plug-connected") }} Verbindung

Schaltet den leichten Hintergrund-Erkennungs-Loop für diese Organisation ein (fragt nur GetCurrentEvents ab)

Legt fremde Einheiten als schreibgeschützte Platzhalter an und übernimmt deren S4/S5-Status nur im LIS-Ausfall-Fallback.

Sobald der Erkennungs-Loop einen eigenen aktiven Einsatz sieht, startet automatisch eine vollständige Rohdaten-Aufzeichnung (siehe Diagnose-Sektion unten) — spart den manuellen Klick genau während des Einsatzfensters.

Ergänzt einen bereits bestehenden, aktiven Einsatz (per Einsatznummer zugeordnet) um Einsatzort, Einsatzcode/Diagnose, BMA-Nr., Zu-/Absagen und das sichtbare Meldungsprotokoll aus DIBOS. Unabhängig von "Voll-Tracing automatisch starten" nutzbar — läuft über den leichten Erkennungs-Loop (kein Rohdaten-Mitschnitt, geringere Speicherlast). Läuft zusätzlich ein Voll-Tracing, übernimmt dessen Poll-Zyklus die Anreicherung.

Legt einen neuen Einsatz an, wenn kein passender existiert (Matching über Leitstellennummer, sonst Alarmstichwort+Adresse im Zeitfenster) — für den Übergang, bis die LIS/IPR-Anbindung abgeschaltet wird. Unabhängig von der Anreicherung oben aktivierbar; bis dahin können beide Anbindungen parallel laufen.
